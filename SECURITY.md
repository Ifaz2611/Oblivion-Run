# Security Policy

## Supported versions

Security fixes are handled on the latest code in the repository's default
branch. The project does not currently publish a formal version support
matrix.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue, discussion,
or pull request.

If GitHub's private vulnerability reporting is enabled for this repository,
use **Security → Report a vulnerability** on the repository page. If it is not
available, contact the repository maintainers privately through GitHub and ask
for a secure reporting channel before sharing sensitive details.

Include the affected revision or file, the impact, and clear reproduction
steps. Avoid including real user data or secrets in a report. Please allow the
maintainers reasonable time to investigate and coordinate a fix before any
public disclosure; there is no guaranteed response or resolution time.

The maintainers will acknowledge reports when practical, investigate their
impact, and coordinate any fix or disclosure with the reporter.
